Logical Operators  (Boolean --> Boolean)
------------------

Bool1   Bool2   AND     OR

----------------

Right Shift --> >> --> moves bits towards right. 4>>2-->1
Left Shift ---> << 


Iteration(Indexing) and Slicing 
-------------------------
len(obj)  --> length of an iterableObj.
Iteration 
-----------
index Number ---> starts with 0
--> iterableObj[index]
>> negative indexing --> iterableObj[-1] --> last element

Slicing 
--------
>> Extract part of obj.
obj[start:] ---> obj[2:] --> [2,3,4,5......]
obj[:end] --> obj[:4] --> [0,1,2,3]
obj[start:end] --> obj[2:5] --> [2,3,4]
obj[::-1] --> reversed obj



Control Flow
------------
>> It decides which part  of the program should.

If block
---------
syntax:
--------
if condition:
    block of code
>> condition--> True, then block of code will be executed.

Else Block 
-----------
else:
    block of code

it always comes with if block. when if block's condition fails, else block will get executed.

Elif Block 
------------
elif condition:
    block of code 
>> condition--> True, then block of code will be executed.

Nested If 
-----------
if condition1:
    if condition2:
        block of code

Exception Handling
--------------------

Error
------
>> An error is a problem in a program that stops it from running properly.

Syntax Error 
------------
These are mistakes in the structure (grammer) of the code.
The program won't even run if there is a syntax error.

Runtime Errors (Exceptions)
---------------------------
Errors that occur while the program is running.
Example: TypeError, ZeroDivisionError, nameError, ValueError

Exception Handling(syntax)

try:
    block of code 
except nameOfTheError:
    block of code
except nameOfTheError:
    block of code

    block of code
