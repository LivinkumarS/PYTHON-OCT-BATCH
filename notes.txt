Python
-------
>> Python is a high level, interpreted and general purpose programming language.
interpretation --> line by line. Ex: Python

It is known for it's simple syntax.
Versatile.

Extension ---> .py
To execute python file in terminal --> python filename.py

Printing 
----------
print(data) ---> the data will be shown at the output

Prompting
-------------
input() --> get input from user.

Syntax of Python 
-----------------
>> Python is case-sensitive.(a is not equal to A)
>> To Create comments --> # as prefix or ''' comment '''

Variables 
----------
>> container  ---> we can store a piece of data in it.
varName = data

>> It is a named memory location used to store data.

naming rules
-------------
>> must start with a letter
>> No spaces
>> cannot use keyword as a variable name.


Python Datatypes 
-----------------
type(obj) ---> finds out the datatype of the object

INT ---> Whole Numbers. 1,2,3,0,-1,-111
FLOAT ---> Decimal Numbers. 2.3, 3.14

STRING ---> Collection of Char wrapped with either '' or ""
Concatination---> + --> str1+str2=str1str2
Formatted String --> f' {var1} {var2}....  '

Boolean ---> True or False

Type Casting 
-------------
int(obj) ---> convert into integer
float(obj) ---> convert into float
str(obj) ---> convert into str


Operators 
----------

45 / 9 = 5
/--> Operator
45,9 ---> operands 
5 --> Result

>> Operators are symbol that perform operation on operands.

Arithmetic Operators
----------------------
addition --> +
subtraction --> -
multiplication --> *
division --> /
floor division ---> //.
modulus --> (reminder) %. 3%10 --> 10*0 --> 0 --> 3
Exponentiation --> **. 2**2--> 4

BODMAS ---> Bracket Of Div Mul Add Sub

Comparison Operators (Boolean)
---------------------
== ---> Equal
!= ---> Not equal
< ---> Lesser than
> ---> Greater than
<= --> Lesser or Equal
>= --> Greater or Equal

Assignment Operators  (used to assign value to variables)
---------------------
= --> assign
+= --> add and assign
-= --> sub and assign
*= --> mul and assign
/= --> div and assign
//= --> floor div assign
%= --> mod and assign
**= --> expo and assign

Logical Operators  (Boolean --> Boolean)
------------------
AND ---> and --> both are True --> True
OR  ---> or  --> anyone is True --> True. 
Both are False --> False.
NOT --> not --> invert a boolean.

Bool1   Bool2   AND     OR 
True    True    True    True 
False   True    False   True 
True    False   False   True 
False   False   False   False

Bitwise Operator  (operates with bits)
----------------
AND --> & --> and operation with bits. Ex: 9&11
OR --> | --> or operation with bits. Ex: 5&20
NOT --> ~ --> not operation with bits. ~7 (~n=-(n+1))
Right Shift --> >> --> moves bits towards right. 4>>2-->1
Left Shift ---> <<
